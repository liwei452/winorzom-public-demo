# 威诺智贸通 WINORZOM · 公开版 Demo v2

这是一个可直接部署的多页面静态官网 Demo，定位为“AI 外贸增长与销售操作系统”的公开产品站。

## 当前页面
- `index.html`：品牌首页 / 广告主落地页
- `product.html`：产品能力全景
- `customer-development.html`：AI 外贸获客 / 客户开发
- `sales-workbench.html`：外贸 CRM / AI 销售工作台
- `inquiry.html`：AI 询盘助手
- `growth.html`：SEO / GEO / AEO / 自然增长
- `solutions.html`：行业解决方案
- `about.html`：关于我们

## v2 UI 调整
- 首屏改为深海军蓝 AI 产品风，降低传统“蓝白卡片 SaaS 模板感”
- 首页使用大主视觉 + 今日优先客户工作台建立产品感
- 中段采用 Bento 信息架构，不再六张卡片平均用力
- 产品工作台使用 DEMO 示意数据，避免虚构真实经营指标
- 首页 / 产品能力 / 客户开发三页已重点重构，其他页面共享同一视觉系统
- 桌面与移动端均保留响应式结构

## SEO / GEO / AI 搜索准备
- 每页独立 `<title>` 与 meta description
- 页面主题与 H1 一一对应
- FAQPage / Organization / SoftwareApplication JSON-LD
- 语义化 H1/H2/H3 与内部链接
- 关键词按页面意图拆分：AI外贸获客、外贸CRM、AI询盘、SEO/GEO 等
- FAQ 与回答式内容兼顾传统 SEO 与生成式搜索理解

## 公开传播边界
公开站只讲：
1. 能帮客户做什么
2. 客户如何使用
3. 最终业务结果是什么

不公开：底层数据源组合、Signal Router、判断逻辑、证据权重、内部评分、Agent 编排与技术实现细节。
